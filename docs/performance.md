# 测试版性能记录

2026-09-14，Windows x64，.NET SDK 8.0.425，Release。此记录区分硬件测试与模拟测试，不代表 MVP 全部验收通过。

## 麦克风采集

命令：`scripts/check.ps1 -Project tests/VoiceTyper.Windows.Tests/VoiceTyper.Windows.Tests.csproj -Filter 'Category=Hardware'`。

真实默认麦克风连续 50 次 Start/Stop 全部通过。每次输出非空、偶数字节 PCM，停止返回后没有后续回调。

| 测量 | 结果 |
|---|---|
| 首次 StartAsync 调用到首帧 | 23.5 ms |
| 第 2 次 | 18.4 ms |
| 后续 49 次范围 | 9.8–26.1 ms |
| 首帧长度 | 258 bytes |

计时从测试调用 StartAsync 开始，包含本地设备初始化；不包含实体键盘 Hook、前台窗口捕获、UI、网络和 ASR。因此不能等同于 Hotkey → First Audio Frame，亦不能据此声称开头绝不丢字。设备开始采集前的声音无法由预缓冲恢复。

## 管线

自动化测试覆盖 ASR 建连延迟 0 / 100 / 300 / 800 ms，验证已采集音频顺序及 Stop 回调尾部都保留。实时待发送音频最多 320 KB（约 10 秒），积压超限报错退出，不覆盖开头。

## 2026-09-15 托盘与设置窗口内存

最新版自包含包在同一台 Windows 机器上测得：使用 `--background` 启动并保持设置窗口未创建时，约为 61.6 MB working set / 15.7 MB private bytes；打开完整 WPF 设置窗口后约为 277.8 MB / 224.4 MB；窗口最小化并隐藏到托盘后约为 284.9 MB / 214.7 MB。隐藏窗口不会卸载已创建的 WPF 视觉树，因此低内存常驻路径是开机或命令行后台启动，并在无需设置时不打开设置窗口。

提示音文件总计约 0.4 MB，录音悬浮窗延迟到首次录音才创建。当前差距主要来自自包含 .NET/WPF 运行时和完整设置界面，不能只用任务管理器 working set 与采用其他 UI 技术的程序直接类比。
