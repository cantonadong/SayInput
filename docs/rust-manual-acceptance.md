# SayInput 人工验收

入口为 `artifacts/SayInput.exe`；data 与 recordings 同处该目录。开发过程中不自动运行测试、启动应用或采样性能。

1. 确认旧配置、麦克风选择及 DPAPI 凭据继续生效；无法解密时能重输，普通设置保存不应破坏凭据。
2. 界面自动跟随 Windows 系统界面语言，中文使用简体中文，其余使用英文；无语言选择项。修改系统界面语言后重新启动核对。
3. 对照旧版外观：设置窗口外框 430×700 逻辑像素，100% 时相应为430×700物理像素，150%时645×1050；默认字号12、标题16，保留品牌42、24/18边距、64标签列、原有Tab和底部92宽按钮。检查缩放及跨屏后的布局。
4. 悬浮窗宽480逻辑像素、圆角18、原半透明背景和边框、22根青绿色历史音量柱；文字17、行高24、最多三行，末行持续显示最新内容。150%时宽720物理像素。窗口不应抢焦点或拦截鼠标。
5. 验证右 Alt 点按和按住模式、快速松开、自动重复和连续会话；右 Alt 不应激活目标应用菜单。Esc 仅录音时拦截，不影响其他应用正常使用。
6. 停止音不应阻塞发送结束或文字输入。比较短句和长句的松开到上屏时间；不得用本地源码判断代替实际延迟测量。
7. 在记事本、浏览器和常用应用中确认终稿只上屏一次。切窗、目标关闭或权限不同时，应明确提示并保留可复制终稿。托盘复制、剪贴板占用和粘贴后恢复也需核对。
8. 本地音量测试可提前结束，十秒自动结束，不上传或归档；连接测试覆盖配置、音频和终止响应。
9. 录音开始后静音输出，停止、取消、失败和退出后恢复每个设备原状态；原先静音的设备不能被取消静音。检查四种提示音和托盘状态图标。
10. 正常停止的音频保存为16kHz/16-bit/mono WAV，最多二十条；取消不提交归档。网络失败后已正常停止的录音应保留。
11. 超过两分钟继续录音；十分钟正常自动停止；慢网络积压不应因旧阈值中断或持续堆积整段音频的内存副本。十二分钟总兜底、发送结束后十五秒等待终稿，超时应明确提示。云端十分钟兼容仍需确认。
12. 保存后立即退出再打开核对配置；后台启动及启动项应指向 artifacts/SayInput.exe，第二实例不能同时监听热键。SimpleWall 刚放行时必须完全重启进程。

## 性能记录

由用户决定运行。在任务管理器记录全新后台启动、打开设置、关闭设置、录音/积压、连续会话结束五个阶段的工作集、私有内存、CPU时间变化、线程及句柄。各阶段稳定三十秒，使用相同设备和操作与旧版比较；区分专用工作集与私有字节，不强制清空工作集制造较低数字。

当前没有新版本的真实内存/CPU、延迟或像素对齐测量，不能把实现目标当作验证结果。

会话故障定位：`data/last-session.log` 仅保留最近一次会话的阶段耗时和错误类别，不记录文字、音频或凭据。若无法上屏，同时核对托盘能否复制本次完整文字；日志中的 `final-received`、`input-start`、`input-completed` 可区分终稿接收和输入阶段。设置页应没有标签及复选框周围的灰色色块，仍需在实际 DPI 下与旧版逐项对照。
