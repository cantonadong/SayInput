# Task 4 — Target Window Capture

保留 IForegroundWindowService 与 TargetWindow；Right Alt DOWN 先捕获，再调度诊断 UI。

- [ ] 测试原窗口快照、空窗口、自身窗口、窗口关闭/句柄归属变化、元数据错误、取消。
- [ ] WindowsForegroundWindowService：捕获 HWND/PID/ProcessName/Title；在获取元数据后校验 HWND 仍属于原 PID。
- [ ] IForegroundWindowApi / Win32ForegroundWindowApi：隔离原生 API，查询进程使用有限权限，Dispose 进程句柄。窗口标题不写日志。
- [ ] EnsureForegroundAsync 本任务只校验原目标仍在前台；失焦返回 false，不调用 SetForegroundWindow。最终恢复焦点受 Windows 限制，留待上屏任务确认策略。
- [ ] 诊断 UI 显示按下时目标，不在松开时重新捕获。
- [ ] build/test、更新本机测试包、记录准确结果。
